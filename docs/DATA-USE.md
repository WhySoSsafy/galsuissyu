# 데이터 활용 증빙

한국관광공사 OpenAPI를 **어느 화면의 어느 항목에** 썼는지 한 장에 정리한 문서입니다.
모든 수치는 `public/data/tour-places.json`을 세어 나온 값이며, `node scripts/fetch-tour-places.mjs`로 재현됩니다.

수집일 **2026-09-20** · 대전광역시(areaCode 3) 전역

---

## 2. 받은 데이터가 화면 어디에 나오는가

| 공사 필드 | 앱에서 보이는 위치 | 화면 문구 |
|---|---|---|
| `title`, `mapx`, `mapy` | 지도 핀, 검색 결과 | 장소명·위치 |
| `firstimage`, `firstimage2` | 검색 결과 썸네일, 상세 상단 사진 | (사진) |
| `usetime`, `restdate` | 상세 > 운영 시간 | `09:00~18:00 · 휴무 월요일` |
| `parking` | 상세 > 주차 | `가능` |
| `chkbabycarriage` | 상세 > 유아차 안내 **원문** | `유아차 안내 원문: …` |
| `exit`, `parking`, `publictransport` | 상세 > **도착과 출입** | `출입통로가 넓어 휠체어 진입 쉬움. 경사로 있음.` |
| `route`, `elevator`, `restroom`, `wheelchair` | 상세 > **내부 이동** | `내부 턱 있음(좌식 공간 진입 시)` |
| `braileblock`, `helpdog`, `audioguide`, `bigprint` | 상세 > **시각 안내** | `점자블록 있음` |
| `signguide`, `videoguide`, `hearingroom` | 상세 > **청각 안내** | (대전 등록 0건 — 공백으로 표시) |
| `stroller`, `lactationroom`, `babysparechair` | 상세 > **영유아 동반** | `유아용 보조의자 있음` |
| `infoname` / `infotext` | 상세 > 추가 안내 | `입 장 료: 무료` |
| `publictransport` 중 저상버스 노선번호 | 대중교통 경로 목록 | `버스 201 [저상버스 등록 노선]` |

**"누구와 함께 가시나요?"에서 고른 동행에 따라** 해당 블록이 위로 정렬되고 `내 일행에 해당` 표시가 붙습니다.
(`src/tour-data.ts`의 `companions`가 동행 유형과 무장애 블록을 연결합니다.)

## 4. OSM과의 관계 — 공사 데이터가 채운 칸

| | OpenStreetMap | 한국관광공사 |
|---|---|---|
| 장소 수 | 1,763 | 231 |
| 휠체어 접근성 표기 | **51곳 (2.9%)** | 무장애 상세 72곳 |
| 운영시간 | 거의 없음 | 204곳 |
| 대표 사진 | 없음 | 213곳 |
| 도로망·경로 탐색 | 노드 62,166 / 간선 83,926 | — |

**공사 데이터가 없었다면 이 앱은 "길은 찾아주지만 그 장소가 어떤 곳인지는 모르는" 상태였습니다.**
반대로 OSM이 없으면 장소는 알아도 **거기까지 가는 길**을 계산할 수 없습니다. 두 데이터가 서로의 빈칸입니다.

이름이 같고 150m 이내면 같은 장소로 보아 공사 기록을 우선합니다 (`includeTourPlaces`, `src/CityExplorer.tsx`).

## 5. 대중교통 경로 — 기록된 응답

ODsay 경로 조회는 일 사용량 한도가 있습니다. 심사 중 같은 경로가 반복 조회되어 한도가 소진되면 핵심 기능인 3D 시뮬레이션이 멈추므로, **대전역에서 출발하는 주요 관광지 10곳의 실제 조회 결과를 `public/data/recorded-routes.json`에 저장해 빌드에 포함**했습니다 (`scripts/fetch-recorded-routes.mjs`).

- 저장된 것은 **실제 ODsay 응답**이며 가공하거나 지어낸 값이 없습니다. 접근성 판정도 원본 그대로 `unknown`입니다
- 화면에 **"저장해 둔 실제 조회 결과예요. 지금 이 순간의 운행 정보는 아니에요."** 를 표시합니다
- `지금 운행 정보로 조회하기` 버튼으로 실시간 조회를 할 수 있습니다
- 저장되지 않은 경로는 평소처럼 실시간 조회합니다

## 5. 해석하지 않은 것

공공데이터를 **오독해서 표시하지 않는 것**을 원칙으로 삼았습니다.

- **`chkbabycarriage`를 접근성 판정으로 쓰지 않았습니다.** 공사 문서상 "유모차대여여부"인데 제공기관마다 대여 뜻과 진입 뜻을 섞어 씁니다(값 분포: 없음 40 / 불가 6 / 가능 1). **원문 그대로** 보여줍니다.
- **무장애 상세가 있다고 해서 `wheelchair: yes`로 바꾸지 않았습니다.** 그 필드는 접근성 *서술*이지 가부 판정이 아닙니다.
- **저상버스는 "저상"이 적힌 줄의 번호만** 추출합니다. 같은 필드에 일반 버스도 적혀 있어, 그것까지 저상으로 쓰면 없는 사실을 만드는 것입니다.
- 비어 있는 항목은 **"없음"이 아니라 "등록되지 않음"** 으로 표시합니다.

## 6. 재현 방법

```bash
# .env.local 에 TOUR_API_KEY (공공데이터포털 일반 인증키, Decoding)
node scripts/fetch-tour-places.mjs     # → public/data/tour-places.json
npm run test:transit                   # 파싱 규칙 검증 포함
```

키는 서버·빌드 환경에만 둡니다. `VITE_` 접두사를 붙이지 않으므로 브라우저 번들에 포함되지 않습니다.
대중교통 경로(ODsay)도 같은 원칙으로 `server/transit.mjs`를 거칩니다.

호출 제한 대응: 초당 제한(코드 23)을 페이싱 신호로 인식해 백오프·재시도합니다. 이 처리를 넣기 전에는 231건 중 151건이 **조용히 유실**됐습니다.
