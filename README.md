# 갈수있슈

**한 사람이 갈 수 있으면, 온 가족이 갑니다.**

반대도 참입니다. 한 사람이 못 가면, 네 사람이 안 갑니다.

가족 여행의 목적지는 최대공약수가 아니라 **최소공배수**로 정해집니다. 계단 때문에 어머니가 못 올라가는 전망대는 네 명 전원의 후보에서 빠집니다. 유아차가 못 들어가는 식당이면 일행 전체가 다른 곳으로 갑니다.

**접근성은 1명의 문제가 아니라 N명의 곱셈 문제입니다.** 그래서 이것은 복지 서비스가 아니라, 관광 수요를 막고 있는 병목을 제거하는 서비스입니다.

대전에 기록된 장소 **1,975곳 중 휠체어 접근성이 표기된 곳은 51곳(2.6%)** 입니다. 나머지 1,924곳은 "갈 수 있는지 모르는 곳"이고, **모르는 곳은 가족 여행 후보에서 제일 먼저 탈락합니다.**

이 숫자는 앱 첫 화면에 그대로 나옵니다. 출처별 내역은 [docs/DATA-USE.md](docs/DATA-USE.md) 4절에 있습니다 — OpenStreetMap 1,763곳에 한국관광공사 관광지 231곳을 합치고, 이름이 같고 150m 이내면 같은 곳으로 본 결과입니다.

## 무엇을 하는가

한국관광공사 관광정보에 OpenStreetMap 도로망과 실제 경로 탐색을 결합해, **출발지에서 목적지까지를 3D로 미리 가봅니다.**

| | |
|---|---|
| **3D 이동 시뮬레이션** | 보행 → 지하철 → 환승 → 버스 → 보행을 하나로 이어서 재생. 구간마다 휠체어·열차·버스 모형이 전환되고 카메라가 따라갑니다 |
| **무장애 정보** | 공사 무장애 여행정보 72곳의 출입구·통로·승강기·점자블록·수어 안내를 **원문 그대로** |
| **동행 기반 안내** | "누구와 함께 가시나요?" — 어르신·유아차·휠체어·시각·청각. 고른 동행에 해당하는 안내가 먼저 나옵니다 |
| **조건부 경로 탐색** | 노드 62,166 / 간선 83,926의 보행 도로망에서 계단·급경사·거친 노면을 피하는 A* |
| **제보** | 확인한 접근성을 OpenStreetMap 공개 노트로 되돌려, 다음 사람의 빈칸을 줄입니다 |

**데이터 활용 상세는 [docs/DATA-USE.md](docs/DATA-USE.md)** — 어느 API의 어느 필드가 어느 화면에 나오는지 한 장으로 정리했습니다.

## 30초 둘러보기

사이트에 들어오면 소개 화면이 뜨고, **`▶ 3D 시뮬레이션 보기`** 를 누르면 `대전역 → 한빛탑`이 바로 재생됩니다. 검색부터 하실 필요가 없습니다.

**대전역에서 출발하는 주요 관광지 10곳의 경로는 실제 조회 결과를 빌드에 포함했습니다.** 한빛탑·오월드·한밭수목원·시립미술관·뿌리공원·우암사적공원·대청호·유성온천·동춘당·장태산 — 이 경로들은 외부 API를 호출하지 않으므로 심사 중 한도 소진이나 제공처 장애와 무관하게 항상 재생됩니다. 저장된 결과임을 화면에 표시하며, `지금 운행 정보로 조회하기`로 실시간 조회도 가능합니다.

직접 해보시려면: 장소 찾기에서 검색 → 결과의 `출발`/`도착` → 길찾기 → 대중교통 → `이 경로로 3D 시뮬레이션`

## 우리가 지킨 원칙

**갈 수 있다고 단정하지 않습니다.** 아는 것은 출처와 함께, 모르는 것은 모른다고 보여줍니다.

- 무장애 상세가 있다고 해서 "휠체어 가능"으로 바꾸지 않습니다. 그 필드는 접근성 *서술*이지 가부 판정이 아닙니다
- `chkbabycarriage`는 공사 문서상 "유모차대여여부"이고 제공기관마다 뜻이 다릅니다. **원문 그대로** 보여줍니다
- 저상버스는 "저상"이 적힌 줄의 번호만 씁니다. 같은 필드의 일반 버스를 저상으로 쓰면 없는 사실을 만드는 것입니다
- 빈 항목은 **"없음"이 아니라 "등록되지 않음"** 입니다
- 경로 미리보기는 실제 GPS 위치가 아니며, 저상버스 배차·엘리베이터 운영·실시간 도착을 보장하지 않습니다

**대전 전체에 청각 안내가 등록된 관광지는 0곳입니다.** 이 숫자를 숨기지 않고 첫 화면에 표시합니다. 그것이 저희가 채우려는 빈칸이기 때문입니다.

## 접근성

접근성을 다루는 앱이 스스로 접근성이 나쁘면 안 됩니다. 브라우저에서 측정해 고쳤고, 테스트로 고정했습니다(`tests/accessibility.test.mjs`).

- 본문 대비 **4.5:1 이상** — 도착 버튼 3.59:1, 보조 텍스트 3.26:1이었던 것을 교정
- 터치 타깃 **44px 이상**
- 지도로 건너뛰는 **스킵 링크** — 그 전까지 지도까지 116번 탭
- `prefers-reduced-motion`을 소개 화면·패널 전환·시뮬레이션 카메라 전부에서 준수
- **카메라가 진행 방향으로 회전하지 않습니다.** 어지럼증 유발 요인이라 의도적으로 제외했습니다

## 실행

Node.js 22 이상.

```bash
npm ci
npm run assets:restore   # 지도 타일·3D 모형 (약 90MB, SHA-256 검증)
npm run dev              # http://localhost:5173
npm run dev:api          # 별도 터미널 — 대중교통 경로 (ODsay)
```

`.env.example`을 참고해 `.env.local`에 키를 넣습니다. **키는 서버에만 두며 `VITE_` 접두사를 붙이지 않습니다.**

| 변수 | 용도 |
|---|---|
| `TOUR_API_KEY` | 공공데이터포털 한국관광공사 인증키 |
| `ODSAY_API_KEY` | 대중교통 경로 |
| `ODSAY_SERVICE_URI` | ODsay 웹 키 등록 도메인 |

```bash
npm run test:transit     # 전체 테스트
npm run build            # 프로덕션 빌드
```
